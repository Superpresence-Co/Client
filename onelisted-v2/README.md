# Onelisted V2

## Embed (Webflow → Site settings → Custom code)

Head:
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Superpresence-Co/cdn@onelisted-v2-v1.0.0/onelisted-v2/style.css">
```

Before `</body>`:
```html
<script src="https://cdn.jsdelivr.net/gh/Superpresence-Co/cdn@onelisted-v2-v1.0.0/onelisted-v2/script.js" defer></script>
```

Replace `v1.0.0` with the latest tag. Use `.min.js` / `.min.css` for auto-minified files.
