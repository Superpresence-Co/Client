# Superpresence V2.5

## Embed (Webflow → Site settings → Custom code)

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Superpresence-Co/cdn@superpresence-v2.5-v1.0.0/superpresence-v2.5/style.css">
```

Before `</body>`:
```html
<script src="https://cdn.jsdelivr.net/gh/Superpresence-Co/cdn@superpresence-v2.5-v1.0.0/superpresence-v2.5/script.js" defer></script>
```

Replace `v1.0.0` with the latest tag. Use `.min.js` / `.min.css` for auto-minified files.
